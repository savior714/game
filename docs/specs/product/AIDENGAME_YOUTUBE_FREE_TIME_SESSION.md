# AidenGame YouTube 자유시간 세션 제품 스펙

- 상태: `APPROVED_PRODUCT_CONTRACT_IMPLEMENTED`
- 기준일: 2026-08-07
- 적용 범위: `domains/reward/`의 유튜브 10분 보상 사용 흐름
- 갱신 책임: 보상 정책, 외부 실행 방식, 타이머 종료 계약 또는 브라우저 지원 경계가 바뀔 때

## 1. 목적

아이가 보석을 `유튜브 10분`으로 교환한 뒤 보호자 승인을 받아 자유시간을 시작하면 다음을 제공한다.

1. YouTube는 AidenGame 내부 임베드가 아니라 별도 브라우저 탭의 공식 YouTube 페이지에서 연다.
2. AidenGame은 독립적인 10분 카운다운을 시작한다.
3. 지원 브라우저에서는 카운다운을 Document Picture-in-Picture 창으로 띄운다.
4. 지원하지 않거나 PiP 생성이 실패하면 AidenGame 탭 안의 고정 타이머로 대체한다.
5. 종료 시 강한 소리와 명확한 시각 경고로 YouTube 탭을 닫고 게임으로 돌아오도록 안내한다.

이 기능은 YouTube 시청 여부를 측정하거나 영상 재생을 보상하는 기능이 아니다. 보석으로 교환하는 대상은 특정 영상이나 조회수가 아니라 보호자가 허용한 10분 자유시간이다.

## 2. 현재 제품 계약과 연결

현재 보상 시스템은 다음 상태를 이미 소유한다.

- 보석 수: `gems`
- 사용 가능한 YouTube 시간: `youtube_minutes`
- 기본 교환: 보석 1개당 YouTube 10분
- 사용 전 보호자 잠금 해제

새 기능은 이 재고 계약을 유지한다. `youtube_minutes`는 계속 10분 단위로 적립·차감하며, 활성 카운다운은 별도의 세션 상태로 관리한다.

## 3. 정책 결정

### 3.1 외부 YouTube 탭만 사용

초기 버전은 다음을 금지한다.

- AidenGame 내부 YouTube IFrame 플레이어
- YouTube Data API 또는 IFrame Player API 사용
- 특정 영상 재생 여부, 재생 위치, 시청 시간 또는 조회 완료 여부 수집
- 영상을 봤다는 이유로 추가 보상 지급
- YouTube 플레이어 위에 타이머, 버튼 또는 오버레이 표시
- YouTube 광고, 추천, 컨트롤 또는 표준 사용자 경험 변경

외부 탭은 `window.open()` 또는 동등한 사용자 시작 링크로 공식 YouTube URL을 연다. AidenGame은 외부 탭의 DOM, 재생 상태, 계정 또는 시청 기록에 접근하지 않는다.

### 3.2 자유시간과 영상 접근을 분리

사용자 문구는 `유튜브 영상 잠금 해제`가 아니라 `유튜브 자유시간 10분 시작`으로 통일한다.

- 보석은 자유시간 재고로 교환한다.
- 부모 승인은 자유시간 사용 승인이다.
- 아이가 어떤 영상을 실제로 재생했는지는 AidenGame이 판단하지 않는다.
- YouTube 탭을 일찍 닫더라도 자동 환불하지 않는다.
- 외부 탭이 열리지 않으면 세션을 시작하지 않고 10분도 차감하지 않는다.

## 4. 사용자 흐름

### 4.1 교환

1. 아이가 보석 상점에서 `유튜브 10분`을 선택한다.
2. 보석 가격만큼 차감한다.
3. `youtube_minutes`에 10분을 더한다.
4. 보관함에는 사용 가능한 총 분을 표시한다.

이 단계에서는 YouTube를 열거나 타이머를 시작하지 않는다.

### 4.2 사용 승인

1. 아이가 보관함의 YouTube 시간을 누른다.
2. 사용 가능한 시간이 10분 미만이면 시작할 수 없다.
3. 기존 보호자 잠금 해제를 통과한다.
4. `유튜브 자유시간 10분 시작` 버튼을 표시한다.
5. 버튼 주변에 다음을 명시한다.
   - 새 YouTube 탭이 열린다.
   - 게임 탭을 닫지 않아야 타이머와 종료 알림이 유지된다.
   - YouTube 탭을 일찍 닫아도 사용 시간은 환불되지 않는다.

### 4.3 시작 트랜잭션

시작 버튼의 한 번의 실제 클릭은 하나의 시작 시도만 만든다.

1. 이미 활성 세션이 있으면 새 탭이나 새 차감을 만들지 않고 기존 타이머를 표시한다.
2. 사용자 클릭 컨텍스트에서 경고음용 오디오를 활성화할 준비를 한다.
3. 보호자가 설정한 YouTube 대상 URL을 새 탭으로 연다.
4. 팝업 차단 등으로 새 탭 생성이 거부되면:
   - 10분을 차감하지 않는다.
   - 세션을 저장하지 않는다.
   - 팝업 허용 방법을 짧게 안내한다.
5. 브라우저가 새 탭 생성을 수락한 경우에만:
   - `youtube_minutes`에서 정확히 10분을 한 번 차감한다.
   - 활성 세션을 저장한다.
   - 타이머 UI를 연다.
6. 차감·세션 저장·타이머 시작 중 일부만 성공한 반쪽 상태를 남기지 않는다. 실패 시 재시도 가능 상태로 복구한다.

외부 탭이 실제 네트워크 오류 없이 YouTube를 끝까지 표시했는지는 AidenGame이 판정하지 않는다. 시작 성공의 경계는 브라우저가 사용자 클릭에 따른 새 탭 생성을 수락하고 로컬 세션 커밋이 완료된 시점이다.

## 5. YouTube 대상 URL

초기 버전은 아이가 임의 URL을 입력하게 하지 않는다.

- 기본값: `https://www.youtube.com/`
- 선택 사항: 보호자 화면에서 하나의 시작 URL을 설정
- 허용 프로토콜: `https:`만
- 허용 호스트: `youtube.com`과 그 하위 도메인, `www.youtube.com`, `m.youtube.com`, `youtu.be`
- 사용자 이름, 비밀번호, 비표준 포트, `javascript:` 또는 기타 스킴은 거부
- 검증 실패 시 기본 YouTube URL로 되돌리거나 fail-closed한다.

활성 세션에는 전체 영상 URL이나 영상 ID를 분석·저장하지 않는다. 디버깅에 필요하면 `youtube.com` 계열을 열었다는 범주만 기록한다.

## 6. 타이머 계약

### 6.1 시간 계산

타이머는 1초마다 남은 값을 감소시키는 카운터를 시간 권위로 사용하지 않는다.

- 시작 시 `startedAt`과 `deadline = startedAt + 10분`을 저장한다.
- 남은 시간은 항상 `max(0, deadline - Date.now())`로 다시 계산한다.
- `setTimeout`, `setInterval`, 애니메이션 프레임은 화면 갱신 수단일 뿐 시간 권위가 아니다.
- 탭이 백그라운드에 있거나 컴퓨터가 잠자기 상태였다가 돌아와도 현재 시각으로 즉시 보정한다.

### 6.2 활성 세션 수

- 한 기기에서 활성 YouTube 자유시간 세션은 최대 1개다.
- 사용 가능한 시간이 20분 이상이어도 한 번의 시작은 10분만 소비한다.
- 활성 세션 중 다시 누르면 추가 차감 없이 기존 세션을 표시한다.
- 10분 연장은 초기 버전 범위가 아니다.

### 6.3 세션 상태

권장 저장 계약:

```text
version: 1
sessionId: string
status: running | expired | acknowledged
startedAt: epoch milliseconds
deadline: epoch milliseconds
durationMs: 600000
warningEmittedAt: epoch milliseconds | null
expiredAt: epoch milliseconds | null
acknowledgedAt: epoch milliseconds | null
```

로컬 저장 키의 제안 이름은 `study_youtube_free_time_session_v1`이다. 정확한 키 이름은 구현에서 정하되 버전과 마이그레이션 경계를 가져야 한다.

### 6.4 재로드와 비정상 종료

- AidenGame 탭 새로고침: 저장된 활성 세션을 복원한다.
- 컴퓨터 절전 후 마감 경과: 복귀 즉시 만료 상태로 전환한다.
- PiP 창을 닫음: 세션은 계속되며 게임 탭의 고정 타이머로 전환한다.
- YouTube 탭을 닫음: 세션은 계속되며 환불하지 않는다.
- AidenGame 탭 또는 브라우저를 완전히 닫음: 종료 알림을 보장할 수 없다. 다음 실행 시 만료 상태를 복원해 종료 사실을 표시한다.
- 여러 기기 간 활성 타이머 동기화는 초기 버전 범위가 아니다.

## 7. 타이머 표시

### 7.1 우선 표시: Document Picture-in-Picture

브라우저가 `documentPictureInPicture.requestWindow()`를 지원하고 사용자 시작 조건을 만족하면 항상 위에 표시되는 작은 창을 사용한다.

필수 표시:

- `유튜브 자유시간`
- `MM:SS` 남은 시간
- 진행률
- `게임 탭을 닫지 마세요`
- PiP가 닫혀도 세션은 계속된다는 안내

PiP 생성 실패는 세션 실패가 아니다. 외부 YouTube 탭과 세션이 이미 정상 시작됐다면 즉시 게임 탭 고정 타이머로 대체한다.

### 7.2 대체 표시

Document PiP를 지원하지 않는 브라우저에서는 게임 탭 상단 또는 우측에 고정 타이머를 표시한다.

- 페이지 콘텐츠나 보상 바를 가리지 않는다.
- 키보드와 보조 기술에서 남은 시간을 확인할 수 있다.
- 브라우저 탭 제목에도 남은 시간을 짧게 표시할 수 있다.
- 별도의 일반 팝업 타이머 창은 브라우저 차단과 창 관리 문제가 있어 필수 계약으로 삼지 않는다.

## 8. 경고와 종료

### 8.1 사전 경고

- 1분 남음: 짧은 경고음 1회와 `1분 남았어요` 시각 안내
- 10초 남음: 숫자 카운트다운을 더 크게 표시
- 같은 경고는 한 세션에서 정확히 한 번만 발생

### 8.2 종료 경고

마감 시 다음을 동시에 수행한다.

- 상태를 `expired`로 저장
- 반복 경고음 시작
- 타이머를 `00:00`으로 고정
- 빨간색 또는 고대비 종료 화면 표시
- `시간이 끝났어요. YouTube 탭을 닫고 게임으로 돌아오세요.` 표시
- 사용자가 `확인했어요`를 누를 때까지 경고 상태 유지

경고음은 브라우저가 허용한 범위에서 충분히 눈에 띄게 반복한다. 웹페이지는 운영체제 음량을 강제로 높일 수 없으므로 `최대 시스템 음량 보장`은 수용 기준이 아니다.

빠른 섬광은 사용하지 않는다. 시각 경고는 광과민성 위험을 줄이도록 3Hz 미만의 느린 펄스 또는 고정 고대비 화면을 사용하고 `prefers-reduced-motion`을 존중한다.

### 8.3 외부 탭 제어 한계

AidenGame은 YouTube 탭의 영상 정지나 현재 재생 상태를 보장하지 않는다.

- 스크립트가 연 창의 참조를 보유한 경우 종료 시 닫기를 시도할 수 있으나 best-effort 보조 동작일 뿐이다.
- 자동 탭 닫기, 영상 정지 또는 YouTube 재생 종료는 필수 수용 기준이 아니다.
- 핵심 계약은 정확한 시간 계산과 강한 종료 알림이다.

## 9. 오디오 계약

- 시작 버튼 클릭 시 Web Audio `AudioContext`를 생성하거나 `resume()`해 사용자 제스처 기반 재생 권한을 준비한다.
- 오디오 준비 실패 시 세션은 계속되지만 명확한 무음 경고 표시를 유지한다.
- 경고음은 합성음 또는 저장소 내 짧은 정적 자산을 사용할 수 있다.
- 네트워크 오디오 자산에 의존하지 않는다.
- 음소거, 출력 장치, 시스템 음량 또는 브라우저 정책으로 실제 소리가 나지 않을 가능성은 사용자에게 숨기지 않는다.

## 10. 개인정보와 아동 보호

초기 버전은 YouTube API 클라이언트가 아니며 다음 데이터를 수집하지 않는다.

- YouTube 계정
- 영상 ID, 제목, 채널 또는 검색어
- 시청 기록이나 실제 재생 시간
- 좋아요, 구독, 댓글 또는 공유 행동
- YouTube 광고나 추천 상호작용

AidenGame이 저장하는 것은 자유시간 세션의 시작·마감·확인 시각과 보상 재고뿐이다. 향후 내부 임베드나 YouTube API 사용을 검토한다면 별도 제품·개인정보·아동 대상 정책 검토 없이 이 스펙을 확장하지 않는다.

## 12. 수용 기준

다음 조건을 모두 만족해야 구현 완료로 판정한다.

1. 보석 교환으로 기존 계약대로 YouTube 10분이 적립된다.
2. 보호자 승인을 통과하기 전에는 외부 탭, 차감, 세션이 시작되지 않는다.
3. 시작 버튼 한 번으로 외부 탭 생성 시도는 정확히 한 번 발생한다.
4. 팝업 차단 시 `youtube_minutes`는 변하지 않고 활성 세션도 없다.
5. 외부 탭 생성이 수락되면 10분이 정확히 한 번만 차감되고 세션이 하나 생성된다.
6. 중복 클릭 또는 활성 세션 재진입은 추가 차감이나 두 번째 세션을 만들지 않는다.
7. 남은 시간은 `deadline - 현재 시각`으로 계산되어 백그라운드, 재로드, 절전 후에도 정확히 보정된다.
8. 지원 브라우저에서는 Document PiP를 시도하고, 실패 또는 미지원 시 같은 상태를 게임 탭에서 표시한다.
9. 1분 경고와 만료 경고는 세션당 정확히 한 번 시작된다.
10. 만료 경고는 사용자가 확인할 때까지 시각적으로 유지되고, 오디오가 허용된 경우 반복 재생된다.
11. AidenGame은 YouTube IFrame/API, 재생 상태 조회 또는 시청 데이터 저장을 사용하지 않는다.
12. 빠른 섬광 없이 키보드와 보조 기술로 시작·확인 흐름을 사용할 수 있다.

## 13. 검증 전략

### 13.1 순수 상태 검증

가짜 시계로 다음을 독립 검증한다.

- 세션 생성과 10분 deadline
- 중복 시작 차단
- 재로드 복원
- 1분 경고 exactly-once
- 만료 exactly-once
- 절전 시간을 모사한 큰 시각 점프
- 만료 확인과 세션 정리

### 13.2 브라우저 검증

실제 YouTube 네트워크에 의존하지 않고 테스트용 외부 URL과 `window.open` 스파이를 사용한다.

- 팝업 성공과 실패
- 성공 후 정확히 한 번 차감
- 실패 시 무차감
- PiP 지원·거부·예외 fallback
- 시작 버튼 더블클릭
- 활성 세션 중 재진입
- 새로고침 후 남은 시간 복원
- 종료 경고와 확인
- 페이지 오류, 콘솔 오류, 실패한 로컬 자산 요청 0

실제 YouTube 페이지 열기는 수동 브라우저 smoke로만 확인한다. 외부 사이트의 광고, 로그인, 지역 제한 또는 서비스 상태를 자동 테스트의 합격 조건으로 삼지 않는다.

## 14. 구현 경계

구현은 다음 책임을 한 번에 섞지 않고 순차적으로 닫는다.

1. **세션 상태와 시간 계산**: 외부 탭이나 UI 없이 deadline·복원·만료 계약
2. **외부 탭과 차감 트랜잭션**: 팝업 성공/실패와 정확히 한 번 차감
3. **타이머 표시**: 게임 탭 고정 UI와 Document PiP fallback
4. **경고 수명주기**: 오디오 준비, 1분 경고, 만료, 확인
5. **실제 브라우저 수용**: YouTube 외부 탭과 장시간 백그라운드 동작

각 구현 작업은 하나의 판정 기준으로 독립 검증하며, 다른 책임의 실패는 별도 작업으로 남긴다.

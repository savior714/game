  1. 목표 색을 잘 살펴봐요.
  2. 물감 튜브를 눌러 한 방울씩 넣어요. 비율이 중요해요!
  3. 비슷해지면 완성! 확인하기를 눌러요. 70% 넘으면 성공, 93% 넘으면 별 3개예요.
  4. 어려우면 힌트를 쓰거나, − 버튼으로 방울을 빼서 고쳐 봐요. 틀려도 괜찮아요, 계속 고칠 수 있어요!

물감 섞기 비밀

  • 노랑 + 파랑 = 초록
  • 빨강 + 노랑 = 주황
  • 빨강 + 파랑 = 보라
  • 어떤 색 + 하양 = 연한 색
  • 어떤 색 + 검정 = 진한 색
  • 빨강 + 노랑 + 파랑 모두 = 갈색
